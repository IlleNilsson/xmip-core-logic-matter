# xmip-core-logic-matter

Matter logic technology: an endpoint, cluster and command path in a TLV invoke request becomes a named operation with TLV arguments, and a result or status becomes an invoke response again. A technology of [xmip-core-logic](https://github.com/IlleNilsson/xmip-core-logic).

## Toolchain

`rust-toolchain.toml` pins the toolchain for the whole estate. Do not change it
here.
